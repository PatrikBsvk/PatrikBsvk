# Vibell — Product Vision

## One-liner
**EN:** *"Have an idea. Vibell builds it."*  
**CZ:** *"Měj nápad. Vibell ti ho postaví."*

## Vision
Vibell is a guided wizard that takes a non-programmer from idea to published web app in 30 minutes. Instead of an empty prompt, it offers structured steps, templates, mockups, and click-to-edit. AI agents do the heavy lifting; the user only sees the result.

## Why now (2026)
- LLMs (Claude Sonnet 4.6, Haiku 4.5) ship working apps from structured input.
- Prompt caching makes per-app generation economically viable (~80% gross margin achievable).
- Non-programmers want to build, but Lovable / Bolt / v0 are still too "developer".
- Hosted infrastructure (Vercel, Supabase) lets us abstract DevOps entirely.

## Differentiators
1. **Structured wizard, not a blank prompt** — guided 4-step input.
2. **Template gallery + visual mockups before code** — see it before generate it.
3. **Click-to-edit with icons** — no terminal, no code.
4. **3 variants side-by-side** — pick visually, don't describe verbally.
5. **Hosted by us** — zero friction to publish (own subdomain on `vibell.app`).
6. **Marketplace + creator portfolio** — 70/30 revenue share (80/20 for Pro+).

## Success metrics — MVP

| Metric | Target |
|---|---|
| Beta users | 50 |
| Free → paid conversion | ≥ 5 % |
| Paying customers | ≥ 3 |
| NPS | ≥ 30 |
| Time from idea to published preview | < 30 s |
| Click-to-edit response time | < 10 s |

## North-star metric
**Number of apps published per active user per month.** This captures both engagement and core value delivery.

## Non-goals (explicit)
- No code editor / IDE experience for power users (that's Cursor/Bolt).
- No backend logic builder (Bubble territory).
- No mobile app generation in MVP (phase 3).
- No team collaboration in MVP (phase 3).
