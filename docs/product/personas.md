# Vibell — Target Personas

## Primary: "The Idea Person"
- **Age:** 25–55
- **Examples:** Small business owner, creative, student, freelancer, hobby builder
- **Tech level:** Comfortable with web apps (Notion, Canva, Shopify) but does NOT code
- **Pain:** Has ideas, blocked because tools require code or DevOps
- **Win:** Publishes a working app in an evening without learning to code
- **Lives on:** Web (desktop primarily, mobile in phase 2 / 3)
- **Acquisition channels:** YouTube tutorials, TikTok demos, Product Hunt, founder's network

## Secondary: "Junior dev / vibe coder"
- **Age:** 18–30
- **Examples:** Bootcamp grad, junior at startup, hobby coder, indie hacker
- **Pain:** Wants speed for prototypes, side projects, demos for clients
- **Win:** Ships MVP in one evening instead of one weekend
- **Lives on:** Twitter/X, Hacker News, Reddit r/SideProject

## Tertiary (phase 3): "Agency / freelancer"
- Builds for clients
- Wants white-label, custom domains, team seats

## Voice and tone implications
- Primary persona is non-technical → **NO jargon**.
  - "databáze" → "místo na data"
  - "deploy" → "publikovat"
  - "endpoint" → never used
- **English-first** product copy, **Czech localized** from launch.
- Coach-like, not teacher-like. Encouraging, not condescending.
- Use everyday metaphors ("příklad: tvůj appka je jako recept — Vibell ti přinese ingredience").

## Anti-personas (not for us)
- Senior backend engineer wanting full control → use Bolt or write from scratch.
- Designer wanting pixel-perfect tool → use Webflow / Framer.
- Enterprise IT team needing on-prem → not our market.
