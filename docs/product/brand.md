# Vibell — Brand (WIP)

> **Status:** Brainstorming. Driven by PM (Claude). Founder: Patrik.

## Confirmed
- **Name:** Vibell
- **Domain:** vibell.app
- **Audience:** Non-programmers with ideas (see `personas.md`)

## Working tagline
- EN: *"Have an idea. Vibell builds it."*
- CZ: *"Měj nápad. Vibell ti ho postaví."*

## Open questions (active)

### 1. Brand feel — pick 3 adjectives
Candidates:
- **Modern** (clean, current)
- **Playful** (fun, approachable)
- **Professional** (serious, trustworthy)
- **Friendly** (warm, human)
- **Bold** (confident, eye-catching)
- **Minimal** (no clutter, premium)
- **Vibrant** (colorful, energetic)
- **Calm** (soft, soothing)
- **Premium** (high-end, polished)
- **Quirky** (unique, memorable)

### 2. Reference brands
What brands feel "like Vibell should feel"?
- Examples to consider: Linear, Stripe, Vercel, Notion, Duolingo, Figma, Loom, Framer, Cal.com, Raycast, Arc browser.

### 3. Color direction
- **A. Vibrant gradients** — Stripe, Linear (gradient hero, dark + neon)
- **B. Pastel calm** — Notion, Cal.com (soft, cozy)
- **C. Monochrome + 1 accent** — Vercel, Arc (mostly black/white + one signature)
- **D. Dark + accent** — GitHub, Linear dark mode
- **E. Playful colorful** — Duolingo, Discord (lots of colors, cheerful)

### 4. Logo direction
- **A. Wordmark only** — "vibell" in a custom font (Stripe, Notion)
- **B. Wordmark + symbol** — bell icon + word (Linear, Vercel triangle)
- **C. Abstract symbol** — geometric shape that becomes brand mark
- **D. Mascot + wordmark** — character + word (Duolingo, Mailchimp)

### 5. Coach mascot — yes / no
We discussed an animated Coach character that walks the user through the first project.
- If YES: what kind?
  - Geometric character (like Duolingo's Duo, but not a copy)
  - Animal (owl, bell with eyes, etc. — risk of generic)
  - Abstract orb / shape with personality (Apple Voice Memos vibe)
  - Human-style avatar (risk of uncanny valley)

## Once decided, this doc will contain

- Coach character bible (if applicable)
